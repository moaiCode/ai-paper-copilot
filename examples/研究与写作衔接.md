# 一个问题如何接到实验与写作

状态：**仅完成提案，未实现、未训练、未测量，所有结果尚缺。**这不是论文复现报告；合成任务的可控偏置不能直接推广到真实长文效果。背景范围见[主题页](主题-注意力与长序列.md)，可直接编辑的英文稿见[related-work.tex](related-work.tex)。

## 问题与可证伪假设

问题：在同一个小型检索任务中，加入一个可访问全序列的查询位置，能否缓解纯局部窗口在远距离样本上的失败？

假设：在固定模型规模与训练预算下，“窗口＋全局查询”比纯窗口在远距离样本上有更高准确率；它的内存/耗时是否低于完整注意力，须另行实测。若没有改善，或只在近距离改善，就不支持前一项假设。此处是 Agent 提出的教学实验，没有声称新颖性。

## 最小可执行设计

| 项目 | 拟采用设置，执行前确认实际资源 |
|---|---|
| 数据 | 本地合成键值检索；每个样本含互异键、随机值和末尾查询键，标签为查询键对应值。键表1024项，值表64项；不下载真实语料 |
| 长度与分层 | 训练长度128/256，测试128/256/512/1024；序列为键值对后接查询标记和查询键。按被查值到末尾的token距离分近（≤64）/远（>64）报告，不只看总分 |
| 模型 | 三者统一2层、隐藏维128、4头、同一位置编码和分类头；只改注意力连接 |
| 对照 | 完整连接；左右各32位置窗口；同窗口加末尾全局查询位置。后者是本实验简化mask，不称为完整Longformer实现 |
| 训练 | AdamW，学习率0.0003，batch16，最多1000步；种子0/1/2。训练/验证/测试用不同生成器种子，并检查完整样本无交集 |
| 评价 | 各长度/距离准确率；固定batch与dtype下的步耗时、实际可测内存指标；记录硬件、软件、padding和mask实现 |
| 先行检查 | 每种连接先做1个种子、16步smoke run，检查样本标签、mask连通性、梯度和日志，再决定是否继续完整预算 |
| 资源边界 | 先检测本机可用运行时；不安装训练环境、不启动长任务作为本示例的一部分。执行时再锁定设备、时间上限和依赖 |

重要混杂：用完整注意力矩阵加稠密 mask 并不会自动获得稀疏计算收益。若实现仍是稠密算子，应报告这一事实；准确率实验与稀疏性能基准分开解释。不同设备的内存指标不可直接混算。

模型大小、步数和种子只是最小探测配置，不能保证任务学得会。若所有对照均未学会，先查任务/优化而非给假设判输赢；若smoke失败则保留日志并停止扩大。
