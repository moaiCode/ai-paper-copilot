# 公开论文演练：从阅读走到研究与写作

这组文件演示怎样留下诚实、可接续的科研材料。它们在 `examples/`，不属于正式 Vault；没有伪造 Zotero 记录，也没有把局部 PDF 核查称为全篇 MinerU 解析。核验日期为 2026-11-15。

## 阅读路线

1. 读 [Attention 阅读笔记](attention-阅读笔记.md)：观察完整候选笔记、逐条 claim、原文页定位、AI/HUMAN 分区，以及怎样保留原文内的不一致。
2. 读 [注意力与长序列主题页](主题-注意力与长序列.md)：观察如何把三篇论文连成问题地图，并区分已核查正文与仅读摘要。
3. 读 [研究与写作衔接](研究与写作衔接.md)：看一个问题如何转成最小实验、尚未运行的结果格式与英文草稿。
4. 打开 [references.bib](references.bib) 和 [related-work.tex](related-work.tex)：引用键一一对应，但尚未编译，也不是正式投稿稿件。

可以对主 Codex 说：

> 请使用 ai-paper-copilot 阅读这组示例，先指出哪些步骤已实际核验、哪些只完成设计。然后用我选定的一篇公开论文复走流程：先核对真实 Zotero 身份和全文，再归档，不把示例身份或状态当成我的库记录。

## 为什么笔记仍是草稿

`attention-阅读笔记.md` 的 `type: reading-draft` 表示它还没有绑定真实 Zotero 父条目/附件。`material_status: pdf` 表示本次直接读 PDF，`fulltext_path` 留空；`review_status: unreviewed` 表示你尚未人工核验。`agent_verified` 只描述具体 claim 的来源核查。

示例中的 BibTeX 键是本文件集明确给定的键，尚未声称由你安装的 Better BibTeX 生成。正式使用时应从真实条目取得 key/citekey 并核对 `.bib`，不得复制一个看似合法的 8 位字符串凑字段。

将来归档到 Vault 时，先取得真实条目和选用附件身份，通过真实解析/独立包导出后填写路径，再按正式模板创建或合并笔记。既有 HUMAN 区不从本示例复制覆盖。

## 如何验证这组文件

自动检查适合核对 YAML 可解析、分区标记成对、引用键存在、本地链接存在，以及没有把待运行数值填成零。事实核验还需打开源 PDF；结构检查不会替你确认论文论断。

LaTeX 样例采用普通 `article` 与 BibTeX 接口。在装有 TeX 工具链的独立临时目录中，可以依次执行 `pdflatex related-work.tex`、`bibtex related-work`、再运行两次 `pdflatex`；只有实际得到无缺失引用的编译结果后，才记录“编译通过”。本次没有执行这条链，不要求为看示例先安装 TeX。

继续前最有价值的一步：亲自查看 Attention 的 PDF p.8，确认表格与相邻正文的 EN-FR 数值不一致，并决定论文正式写作前怎样处理这个冲突。
