# 科研 Vault 初始模板

本目录是发行包附带的初始模板。保留完整目录、根 AGENTS.md、配置和全部模板；不预先绑定 Zotero、Obsidian 或 Codex，不包含正式文献、全文包、实验或写作成果。

**正式使用先看套件根目录的《00-安装与首次配置.md》**：选定独立的正式 Vault 路径，再复制本模板、安装项目 skill 并修改全部相关配置。不要把本目录当作默认的正式库或插件输出目标。

| 位置 | 部署后保存什么 |
|---|---|
| 01knowledge | 主题、概念、方法、分歧和知识地图 |
| 02vault | 一篇文献一份正式理解笔记；_index 为导航 |
| 03fulltext | 按文献库和附件 key 归档的独立原文资料包 |
| 04projects | 研究问题、项目状态、实验设计与真实运行记录 |
| 05writing | 草稿、图表清单、项目 bibliography 和修改记录 |
| 06inbox | 临时资料与插件导出的中间笔记 |
| templates | 7 份工作流模板（含跨文献综合）与 5 份知识页专用模板（主题、概念、方法、关系、争议）；字段解释见 `templates/README.md` |

research-profile.json 的 data_dir 和 MinerU backend 为 null，表示尚未配置。示例本机 API 地址和 users/0 仍需按目标环境核对；未选择服务与具体上传范围前不发送 PDF。配置文件不存凭据。

空目录中的 .gitkeep 仅用于随 Git 保留骨架；可在正式使用时保留或移除。项目 .agents/skills、插件内入口和 Obsidian 个人设置在部署时建立，模板不带机器相关的符号链接。

一篇论文的路径：检索与筛选 → Zotero 入库 → 对入选附件按需解析 → 导出原文包 → 生成 AI 笔记 → 用户核查 → 知识综合与研究问题。

文献笔记区分 AI 与 HUMAN 内容，补读保护人工思考。原文解析、Agent 核验和人工认可分别记录。可移植的演练说明在发行包 examples 目录，保持与初始库分离。
