# {{paper}} 投稿检查

按目标 venue 当期官方要求填写；不适用项标明理由。区分真正阻碍提交的问题与可改进项，不凭固定实验数量或摘要词数判定论文不合格。

## 投稿要求

- [ ] 官方要求来源、检查日期、deadline 与时区已记录。
- [ ] 模板、页数、匿名、补充材料和文件类型符合当期要求。
- [ ] 作者、贡献、利益冲突、数据/代码、伦理与 AI 披露按要求确认。

## 科学内容与证据

- [ ] 核心 claim 对应真实实验、数据、证明或文献，强度与证据相符。
- [ ] 数据、协议、基线、重复实验与不确定性的说明足以评价结果。
- [ ] 失败案例、局限和不可比之处已如实表述。
- [ ] 核心数字能回到原始记录与聚合脚本。

## 引用与图表

- [ ] 引用键均存在，题录/版本正确，关键引用确实支持所述主张。
- [ ] 图表数字、单位、caption、编号与正文一致。
- [ ] 图表实际渲染可读，图表源与数据保留。

## 稿件与编译

- [ ] 无未处理的占位符、待补实验、未定义引用与交叉引用。
- [ ] 完成实际 LaTeX 编译并检查最终 PDF，记录剩余问题。
- [ ] 补充材料、链接与代码/数据可访问性已按要求检查。
- [ ] 作者已复核科学内容和最终提交版本。

## 归档与提交

- [ ] 保存源稿、`.bib`、图表源、最终 PDF、补充材料和结果映射。
- [ ] 记录最终版本、检查结果、未解决问题与负责人。
- [ ] 用户明确指示实际投稿/发布后，再执行对外提交。
